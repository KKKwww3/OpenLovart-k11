# 多角度渲染 — 新增模块详细设计方案

> 本文档覆盖三大新增模块：**深度图管线**、**角度向量化控制**、**NB2 模型对接与任务调度**。
> 各模块与现有项目资产（UploadZone、BatchProgress、ResultPreview、useBatchGeneration、imgbb-browser）的复用/集成方式已标注。

---

## 一、概述

### 1.1 设计目标

在现有电商工具面板基础上，新增三大核心模块，将当前「文字 prompt 驱动」的多角度方案升级为「参数向量 + 深度图约束」驱动方案：

| 模块 | 目标 | 现有资产复用 |
|------|------|-------------|
| 深度图管线 | 上传原图后自动生成全局深度图，支持预览与参数调节 | 复用 `UploadZone` 上传、`imgbb-browser` 图片托管 |
| 角度向量化控制 | Azimuth/Elevation 数值滑块 + 预设模板 + 批量点位配置 | 复用 `ECommercePanel` 面板容器 |
| NB2 对接与任务调度 | 封装 NB2 模型入参、提交渲染任务、实时回调 | 复用 `useBatchGeneration` hook 架构、`BatchProgress` 看板、`ResultPreview` 预览、SSE 模式 |

### 1.2 核心数据流

```
原图上传 (UploadZone)
    │
    ▼
深度图生成 ──→ 深度图预览 ←── 深度参数调节
    │                              │
    │                              ▼
    └──────────→ 原图 + 深度图 + 参数 ──→ 绑定存储
                                              │
角度配置 ──→ Azimuth/Elevation ──→ 预设模板
    │                                       │
    ▼                                       ▼
批量点位列表 ──→ 向量化(az/el) ──→ 入参组装
                                         │
                                         ▼
NB2 任务提交 ──→ 任务调度 ←── 实时回调
                         │
                         ▼
                   BatchProgress 看板
                         │
                         ▼
                  ResultPreview 预览 → 导出
```

## 二、深度图控制模块 (DepthMapControl)

### 2.1 模块定位

上传原图后**自动触发**深度图生成，提供预览和参数调节能力。深度图与原图绑定，作为 NB2 渲染的透视约束输入。

### 2.2 组件树

```
DepthMapControl                       # 容器组件，管理深度图全生命周期
├── DepthStrengthSlider               # 深度强度 / 清晰度 / 透视灵敏度滑块
├── DepthPreview                     # 深度图灰度图预览（与原图对比模式）
└── [UploadZone]                      # ✅ 复用，仅用于原图上传
```

### 2.5 内部逻辑

```
generateDepthMap(sourceImage)
  1. status → "generating"
  2. POST /api/depth-map { image: sourceImage }
     - 后端接收 base64，调用深度图算法
     - 返回深度图 URL（imgbb 托管）
  3. status → "ready", depthMapUrl = result.url
  4. 调用 onDepthMapReady(depthMapUrl)

updateParams(partialParams)
  1. 合并 params
  2. 调用 onDepthParamsChange(newParams)
  3. 若已有 depthMapUrl，自动重新生成

resetDepthMap()
  1. status → "idle"
  2. depthMapUrl → null
  3. params → 默认值
```

### 3.6 角度向量化工具

```typescript
// lib/angle-utils.ts

export interface NormalizedAngle {
  /** 归一化方位角 0-1 */
  azNormalized: number;
  /** 归一化仰角 0-1 */
  elNormalized: number;
  /** 弧度制方位角 */
  azRad: number;
  /** 弧度制仰角 */
  elRad: number;
  /** 角度值保留供 NB2 使用 */
  az: number;
  el: number;
}

/**
 * 角度归一化处理
 * 将用户输入的 Azimuth(0-360) / Elevation(-90~90) 转为 NB2 可用格式
 */
export function normalizeAngle(azimuth: number, elevation: number): NormalizedAngle {
  return {
    az: azimuth,
    el: elevation,
    azNormalized: azimuth / 360,
    elNormalized: (elevation + 90) / 180,
    azRad: (azimuth * Math.PI) / 180,
    elRad: (elevation * Math.PI) / 180,
  };
}

/**
 * 批量角度向量化
 */
export function normalizeBatchAngles(points: AnglePoint[]): NormalizedAngle[] {
  return points.map((p) => normalizeAngle(p.azimuth, p.elevation));
}

/**
 * 校验角度范围
 */
export function validateAngle(azimuth: number, elevation: number): {
  valid: boolean;
  errors: string[];
} {
  const errors: string[] = [];
  if (azimuth < 0 || azimuth > 360) errors.push("方位角范围 0-360°");
  if (elevation < -90 || elevation > 90) errors.push("仰角范围 -90°~90°");
  return { valid: errors.length === 0, errors };
}
```

## 四、NB2 对接与任务调度模块 (NB2TaskSchedule)

### 4.1 模块定位

整合原图、深度图、向量化角度参数，按 NB2 模型要求组装入参，提交渲染任务，实时跟踪任务状态，支持失败重试与参数重调。

### 4.2 组件树

```
NB2TaskSchedule                         # 容器组件
├── NB2ParamConfig                      # NB2 渲染参数配置
├── BatchProgress                       # ✅ 复用，任务状态看板
├── ResultPreview                       # ✅ 复用，结果预览
├── TaskRetryPanel                      # 失败重试 + 参数重调
└── [useBatchGeneration]                # ✅ 复用，适配 NB2 入参
```

```typescript
 * 新增：判断任务是否为 NB2 类型
 */
export function isNB2Task(task: BatchTask): boolean {
  return !!task.nb2Params;
}
```

处理流程分支：

```typescript
// useBatchGeneration processTask 内 — 分支逻辑

async function processTask(task: BatchTask, modelId?: number): Promise<BatchTask> {
  if (isNB2Task(task)) {
    return processNB2Task(task);
  }
  return processPromptTask(task, modelId);  // 原有逻辑
}

async function processNB2Task(task: BatchTask): Promise<BatchTask> {
  // 1. 上传原图到 imgbb（复用 uploadImageAndGetUrl）
  const sourceUrl = await uploadImageAndGetUrl(task.nb2Params!.sourceImage);
  const depthUrl = await uploadImageAndGetUrl(task.nb2Params!.depthMap);

  // 2. 组装 NB2 入参
  const request: NB2RenderRequest = {
    sourceImage: sourceUrl!,
    depthMap: depthUrl!,
    angles: [{
      azimuth: task.nb2Params!.angle.az,
      elevation: task.nb2Params!.angle.el,
      azNormalized: task.nb2Params!.angle.azNormalized,
      elNormalized: task.nb2Params!.angle.elNormalized,
    }],
    renderParams: task.nb2Params!.renderParams,
  };

  // 3. SSE 提交
  await generateNB2Stream(request, {
    onStatus: (stage, message) => { /* 更新 task 状态 */ },
    onProgress: (completed, total) => { /* 更新 progress */ },
    onComplete: (result) => { /* 更新 task.result */ },
    onError: (error) => { /* 更新 task.error */ },
  }, supabase);

  return task;
}
```

## 六、关键工作流

### 6.1 单角度渲染流程

```
用户上传原图
    │
    ▼
自动触发深度图生成 ──→ 深度图预览
    │
    ▼
用户调节 Azimuth/Elevation 或点击预设
    │
    ▼
用户调整渲染参数（质量/速度/输出尺寸）
    │
    ▼
提交任务 → 上传原图+深度图到 imgbb → 组装 NB2 入参
    │
    ▼
SSE 提交 POST /api/nb2-render → 实时状态回调
    │
    ▼
BatchProgress 看板更新 → 渲染完成
    │
    ▼
ResultPreview 展示 → 添加到画布 / 下载
```

### 6.2 批量多角度渲染流程

```
用户上传原图
    │
    ▼
自动触发深度图生成
    │
    ▼
切换到「批量」模式
    │
    ├── 手动添加多个角度点位
    │   └── 或 自动生成等距点位（步长45° → 8个角度）
    │
    ▼
用户调整渲染参数
    │
    ▼
提交任务 → 每个角度一个 NB2 子任务
    │
    ▼
串行处理（concurrency=1）或 并行处理（concurrency=2）
    │
    ▼
BatchProgress 逐个完成 → 全部完成后统一展示
    │
    ▼
ResultPreview 网格预览 → 可单图重渲染 → 批量导出
```

### 6.3 失败重试流程

```
某个角度渲染失败
    │
    ▼
TaskRetryPanel 显示失败详情（原参数保留）
    │
    ├── [一键重试] → 使用原参数重新提交
    │
    └── [修改参数重试]
        │
        ├── 调整深度强度/清晰度
        ├── 调整角度值
        └── 调整渲染参数
            │
            ▼
        重新提交该角度任务
```

## 十一、错误处理与边界情况

| 场景 | 处理方式 |
|------|---------|
| 原图上传失败 | UploadZone 已有错误处理，提示重试 |
| 深度图生成失败 | DepthMapControl 展示错误状态 + 重新生成按钮 |
| 深度图质量不理想 | 用户可调节深度参数后重新生成 |
| 角度参数超出范围 | angle-utils 的 validateAngle 拦截 + 表单提示 |
| NB2 模型超时 | TaskRetryPanel 展示超时错误 + 一键重试 |
| NB2 单角度失败不影响其他 | useBatchGeneration 按任务独立处理 |
| 图片超过 imgbb 限制 | 复用现有 `4MB` 校验逻辑 |
| 批量任务中途取消 | cancelBatch 终止剩余待处理任务 |

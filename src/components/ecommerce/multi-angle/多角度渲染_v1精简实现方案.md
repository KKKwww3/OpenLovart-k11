# 多角度渲染 v1 精简实现方案

> 核心思路：新增 `/api/nb2-render` Next.js API 路由 → 转发到 `supabase/functions/v1/nb2-render` Edge Function → 调 NB2 API。
> 与现有的 `/api/generate-image` SSE 管线完全独立，互不干扰。
> v1 范围：角度控件 + NB2 调用 + 结果展示。深度图留 v2。

---

## 一、v1 简化原则

| 决策 | 说明 |
|------|------|
| **新增 `/api/nb2-render` API 路由** | 和 `/api/generate-image` 同级，遵循相同 Next.js 路由转发模式 |
| **Supabase Edge Function 独立** | `supabase/functions/nb2-render/` 接收来自 Next.js 路由的转发请求，body 格式写死 |
| **去掉独立 NB2TaskSchedule** | 不建独立组件目录，逻辑直接写在 MultiAngleModule 里 |
| **去掉独立 DepthMapControl** | v2 再做，v1 通过 prompt 文字描述角度 |
| **去掉 Zustand store** | v1 用组件内 useState，够用 |
| **去掉 BatchAngleConfig（部分）** | v1 只做单角度 + 预设模板一键，批量自定义点位 v2 |

## 三、Next.js API Route：`/api/nb2-render`

### 3.1 代码

```typescript
// src/app/api/nb2-render/route.ts
// 遵循与 /api/generate-image 相同的路由转发模式

import { NextRequest, NextResponse } from "next/server";
import { createServerSupabaseClient } from "@/hooks/useSupabase";

const SUPABASE_URL =
  process.env.SUPABASE_URL || process.env.NEXT_PUBLIC_SUPABASE_URL;
const SUPABASE_ANON_KEY =
  process.env.SUPABASE_ANON_KEY || process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY;

export async function POST(request: NextRequest) {
  try {
    const supabase = createServerSupabaseClient();

    // 提取认证 token（和 generate-image 一致）
    const authHeader = request.headers.get("Authorization");
    let accessToken: string | undefined;

    if (authHeader) {
      accessToken = authHeader.replace("Bearer ", "");
    } else {
      const {
        data: { session },
      } = await supabase.auth.getSession();
      accessToken = session?.access_token;
    }

    const { sourceImage, azimuth, elevation, quality } = await request.json();

    // 输入校验
    if (!sourceImage || typeof sourceImage !== "string") {
      return NextResponse.json(
        { error: "sourceImage is required (base64 string)" },
        { status: 400 },
      );
    }
    if (azimuth == null || azimuth < 0 || azimuth > 360) {
      return NextResponse.json(
        { error: "azimuth must be 0-360" },
        { status: 400 },
      );
    }
    if (elevation == null || elevation < -90 || elevation > 90) {
      return NextResponse.json(
        { error: "elevation must be -90~90" },
        { status: 400 },
      );
    }

    if (!SUPABASE_URL) {
      return NextResponse.json(
        { error: "SUPABASE_URL not configured" },
        { status: 500 },
      );
    }

    // 转发到 Supabase Edge Function
    const edgeUrl = `${SUPABASE_URL}/functions/v1/nb2-render`;

    const headers: Record<string, string> = {
      "Content-Type": "application/json",
    };

    if (accessToken) {
      headers["Authorization"] = `Bearer ${accessToken}`;
    } else if (SUPABASE_ANON_KEY) {
      headers["Authorization"] = `Bearer ${SUPABASE_ANON_KEY}`;
    }

    const edgeResponse = await fetch(edgeUrl, {
      method: "POST",
      headers,
      body: JSON.stringify({ sourceImage, azimuth, elevation, quality }),
    });

    const data = await edgeResponse.json();

    if (!edgeResponse.ok) {
      if (edgeResponse.status === 401) {
        return NextResponse.json(
          { error: "请先登录后再使用此功能", needsAuth: true },
          { status: 401 },
        );
      }
      return NextResponse.json(data, { status: edgeResponse.status });
    }

    return NextResponse.json(data);
  } catch (error: unknown) {
    const message = error instanceof Error ? error.message : "Unknown error";

    if (message.includes("登录")) {
      return NextResponse.json(
        { error: message, needsAuth: true },
        { status: 401 },
      );
    }

    return NextResponse.json(
      {
        error: "Failed to render multi-angle image",
        details: message,
      },
      { status: 500 },
    );
  }
}
```

## 四、Edge Function：`nb2-render`

### 4.1 Edge Function 接收 body

```typescript
// 来自 Next.js 路由转发的 body
{
  sourceImage: string;     // 原图 base64
  azimuth: number;         // 0-360
  elevation: number;       // -90 ~ 90
  quality?: number;        // 1-100，默认 70
}
```

### 4.2 Edge Function 内部组装的 NB2 body（写死）

```
POST {NB2_API_BASE_URL}
Authorization: Bearer {NB2_API_KEY}
Content-Type: application/json

{
  "image": "<sourceImage base64>",
  "azimuth": 0.125,         // azimuth/360 归一化
  "elevation": 0.5,         // (elevation+90)/180 归一化
  "quality": 70,
  "output_format": "png"
}
```

### 4.3 Edge Function 代码

```typescript
// supabase/functions/nb2-render/index.ts
import "jsr:@supabase/functions-js/edge-runtime.d.ts";
import {
  createOptionsResponse,
  createErrorResponse,
  requireAuth,
  corsHeaders,
} from "../_shared/auth.ts";
import { uploadImageToImgbb } from "../_shared/imgbb.ts";

Deno.serve(async (req) => {
  if (req.method === "OPTIONS") return createOptionsResponse();

  try {
    await requireAuth(req);

    const body = await req.json();
    const { sourceImage, azimuth, elevation, quality = 70 } = body;

    // 校验
    if (!sourceImage) return createErrorResponse("sourceImage is required", 400);
    if (azimuth == null || azimuth < 0 || azimuth > 360)
      return createErrorResponse("azimuth must be 0-360", 400);
    if (elevation == null || elevation < -90 || elevation > 90)
      return createErrorResponse("elevation must be -90~90", 400);

    const NB2_API_URL = Deno.env.get("NB2_API_BASE_URL");
    const NB2_API_KEY = Deno.env.get("NB2_API_KEY");

    if (!NB2_API_URL || !NB2_API_KEY) {
      return createErrorResponse("NB2 API not configured", 500);
    }

    // 角度归一化
    const azNormalized = azimuth / 360;
    const elNormalized = (elevation + 90) / 180;

    // 组装 NB2 请求 body（写死格式）
    const nb2Body = {
      image: sourceImage,
      azimuth: azNormalized,
      elevation: elNormalized,
      quality,
      output_format: "png",
    };

    // 调用 NB2（非流式，直接返回图片 base64）
    const nb2Res = await fetch(NB2_API_URL, {
      method: "POST",
      headers: {
        Authorization: `Bearer ${NB2_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify(nb2Body),
    });

    if (!nb2Res.ok) {
      const errText = await nb2Res.text();
      return createErrorResponse(`NB2 error: ${errText.slice(0, 200)}`, 502);
    }

    const nb2Data = await nb2Res.json();
    const resultBase64 = nb2Data.image || nb2Data.result || nb2Data.data;

    if (!resultBase64) {
      return createErrorResponse("NB2 returned no image", 502);
    }

    // 上传到 imgbb
    const imgbbResult = await uploadImageToImgbb(resultBase64);
    if (!imgbbResult) {
      return createErrorResponse("Image upload failed", 500);
    }

    return new Response(
      JSON.stringify({
        imageUrl: imgbbResult.url,
        azimuth,
        elevation,
      }),
      {
        headers: { ...corsHeaders, "Content-Type": "application/json" },
      },
    );
  } catch (err) {
    const msg = err instanceof Error ? err.message : "Unknown error";
    if (msg.includes("Authentication")) {
      return createErrorResponse(msg, 401);
    }
    return createErrorResponse(msg, 500);
  }
});
```

```typescript
// src/lib/angle-utils.ts

/**
 * 校验角度范围
 */
export function validateAngle(azimuth: number, elevation: number): {
  valid: boolean;
  errors: string[];
} {
  const errors: string[] = [];
  if (azimuth < 0 || azimuth > 360) errors.push(`方位角范围 0-360°（当前: ${azimuth}°）`);
  if (elevation < -90 || elevation > 90) errors.push(`仰角范围 -90°~90°（当前: ${elevation}°）`);
  return { valid: errors.length === 0, errors };
}

/**
 * 角度值格式化显示
 */
export function formatAngle(azimuth: number, elevation: number): string {
  return `${azimuth}° / ${elevation >= 0 ? "+" : ""}${elevation}°`;
}

/**
 * 根据角度生成文件名后缀
 */
export function angleToFilename(azimuth: number, elevation: number): string {
  return `A${azimuth}_E${elevation >= 0 ? "+" : ""}${elevation}`;
}
```

### 5.3 `lib/api.ts` — 新增 NB2 方法

```typescript
// 在现有 api.ts 末尾添加

export interface NB2RenderRequest {
  sourceImage: string;   // base64
  azimuth: number;
  elevation: number;
  quality?: number;
}

export interface NB2RenderResponse {
  imageUrl: string;
  azimuth: number;
  elevation: number;
}

export async function nb2Render(
  options: NB2RenderRequest,
  supabase?: SupabaseClient,
): Promise<NB2RenderResponse> {
  const accessToken = await getAccessToken(supabase);

  const headers: HeadersInit = { "Content-Type": "application/json" };
  if (accessToken) headers["Authorization"] = `Bearer ${accessToken}`;

  const response = await fetch("/api/nb2-render", {
    method: "POST",
    headers,
    body: JSON.stringify(options),
  });

  if (!response.ok) {
    const data = await response.json().catch(() => ({}));
    if (response.status === 401 || data.needsAuth) {
      throw new Error("请先登录后再使用此功能");
    }
    throw new Error(data.error || data.details || "NB2 渲染失败");
  }

  return response.json();
}
```

### 简化方案 — 直接手动循环

```typescript
// MultiAngleModule.tsx — v1 最简单实现

const handleGenerate = useCallback(async () => {
  if (!fileBase64 || isProcessing) return;

  setIsProcessing(true);
  setResults([]);

  const angleList = ANGLE_PRESETS; // v1 固定用 7 个预设
  const initialTasks: BatchTask[] = angleList.map((preset, i) => ({
    id: uuidv4(),
    status: "pending" as const,
    prompt: `${preset.name} (A${preset.azimuth}° E${preset.elevation}°)`,
    progress: 0,
    _angleName: preset.name,
    _azimuth: preset.azimuth,
    _elevation: preset.elevation,
  }));

  setTasks(initialTasks);

  for (let i = 0; i < angleList.length; i++) {
    const task = initialTasks[i];
    const preset = angleList[i];

    // 更新为 processing
    setTasks((prev) =>
      prev.map((t) => (t.id === task.id ? { ...t, status: "processing", progress: 5 } : t)),
    );

    try {
      const result = await nb2Render(
        {
          sourceImage: fileBase64,
          azimuth: preset.azimuth,
          elevation: preset.elevation,
          quality: angleConfig.quality,
        },
        supabase,
      );

      setTasks((prev) =>
        prev.map((t) =>
          t.id === task.id
            ? { ...t, status: "completed", result: result.imageUrl, progress: 100 }
            : t,
        ),
      );
      setResults((prev) => [
        ...prev,
        {
          id: task.id,
          imageUrl: result.imageUrl,
          prompt: `${preset.name} (${formatAngle(preset.azimuth, preset.elevation)})`,
        },
      ]);
    } catch (err) {
      setTasks((prev) =>
        prev.map((t) =>
          t.id === task.id
            ? { ...t, status: "failed", error: String(err), progress: 0 }
            : t,
        ),
      );
    }
  }

  setIsProcessing(false);
}, [fileBase64, angleConfig, supabase]);

// UI 复用 BatchProgress + ResultPreview（零改动）
```

# 多角度渲染功能 实现框架逻辑（无抠图，适配任意场景图）

# 一、核心定位（明确边界，解耦抠图）

本模块核心目标：实现「任意场景图/产品图（无需抠图）」的多角度定点渲染，依托原图全局信息、深度图透视约束、向量化角度参数，对接Nano Banana2（NB2）模型，输出多视角完整场景渲染图，适配通用型图片处理需求；抠图功能独立拆分，不耦合至本模块，用户需单独调用抠图组件完成背景分离。

核心原则：全程保留原图完整场景（不做任何背景删除、主体分离），仅通过深度图和角度向量，控制NB2完成整图多角度透视变换，保证场景\+主体同步旋转，不出现失真、拖影、变形。

# 二、整体技术架构（分层清晰，适配NB2对接）

架构核心：以「原图\+深度图\+角度向量」为输入核心，简化冗余逻辑，聚焦多角度渲染本身，解耦抠图、背景替换等无关功能，确保流程简洁、可落地。

# 五、核心业务主流程（可直接给IDE，明确开发顺序）

1. 用户操作：上传任意场景图/产品图（无需抠图）→ 前端完成原图基础预处理（格式、尺寸）→ 预览原图确认无误

2. 深度图生成：前端自动触发深度图生成请求 → 后端调用深度图算法，生成全局深度图 → 前端接收深度图，支持手动调节参数

3. 角度参数配置：用户调节方位角/仰角，或套用角度模板 → 前端将角度参数转化为向量化数据（az/el）

4. 任务提交：用户确认渲染参数（清晰度、批量角度等）→ 前端组装入参（原图\+深度图\+角度向量）→ 提交至后端

5. 模型渲染：后端对接NB2模型，提交渲染任务 → 实时同步任务状态至前端 → 渲染完成，后端接收成品图并存储

6. 结果处理：前端预览多角度成品图 → 可单图重渲染、批量导出 → 任务完成，留存日志与参数模板
